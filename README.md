Aquí tienes un prompt bastante detallado para usar con la IA: "Actúa como un equipo formado por un diseñador UX/UI senior, un desarrollador frontend experto y un consultor de comunicación para clubes deportivos. Quiero una nueva versión web para el Club Judo Legazpi; no quiero una copia, sino un rediseño completo manteniendo identidad visual. Analiza judolegazpi.com como referencia. Conserva logotipo, colores corporativos, fotos reales del club y estilo de marca, pero mejora todo lo demás. Quiero un diseño moderno, elegante, deportivo, sensación profesional, nada infantil, totalmente adaptado a móviles, con navegación muy sencilla. Solo habrá un administrador y ese administrador solo necesita cambiar cosas muy concretas: horarios, calendario, cuerpo técnico, información de Lopivi, documentos en PDF, torneos organizados por el club, imágenes y textos puntuales. Todo lo demás debe ser estático y optimizado para velocidad, SEO y accesibilidad. Usa tecnología moderna, exportable, sin depender de un proveedor cerrado. Piensa en una experiencia de usuario muy intuitiva. Propón la arquitectura completa de la aplicación, sus secciones y pantallas, y explica todas las decisiones de diseño antes de generar la app." Y un consejo final, añádele una frase más: "No tengas miedo de proponer una solución mejor que la actual, prioriza la claridad y la experiencia de usuario." Creo que con eso vas a obtener un resultado mucho mejor que pidiendo solo una web.
